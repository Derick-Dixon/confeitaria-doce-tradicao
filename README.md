# Doce Tradição — Confeitaria (Projeto Final de Desenvolvimento de Interfaces)

Site de confeitaria artesanal, visual rústico (papel kraft, verde-oliva, mel), construído em 3 fases.

| Pasta | O que tem |
|---|---|
| `fase-1/` | HTML semântico + CSS: cabeçalho, hero, cartões, sobre, formulário, rodapé |
| `fase-2/` | + modo claro/escuro, abas e busca no cardápio, cartões explicativos, carrossel, formulário com JS |
| `fase-3/` | + acessibilidade (WCAG): fonte maior, alto contraste, skip link, foco visível, carrossel com pausa, página de login |

## Como rodar
Abra o `index.html` da fase desejada no navegador. Não precisa instalar nada.

## Ferramentas e IA
HTML, CSS e JavaScript puros (sem framework). IA usada: Claude (Anthropic).
